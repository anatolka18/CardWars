# Card Wars — русская QOL/песочница сборка

Ветка [`qol-ru`](https://github.com/anatolka18/CardWars/tree/qol-ru) форка [shishkabob27/CardWars](https://github.com/shishkabob27/CardWars). Содержит **полную русскую локализацию** плюс набор офлайн-изменений баланса для комфортного прохождения без мобильного «пейн-пинчинга». Идеи и направление правок взяты из форка [Laxbby/CardWars](https://github.com/Laxbby/CardWars) и обсуждения [Card Wars for newer Android versions](https://old.reddit.com/r/CardWars/comments/1f9jwzq/card_wars_for_newer_android_versions/).

> Обычная сборка **без** изменения баланса (только перевод) лежит на ветке [`main`](https://github.com/anatolka18/CardWars) и в релизе [`v_RU`](https://github.com/anatolka18/CardWars/releases/tag/v_RU). Эта ветка — для тех, кто хочет песочницу.

Флупни Свинью! Это Adventure Time: CARD WARS! Призывай существ и накладывай заклинания, чтобы прокладывать путь к победе в бою.

* Обычная сборка (только перевод): [`v_RU`](https://github.com/anatolka18/CardWars/releases/tag/v_RU)

## Что изменено в этой сборке (QOL/песочница)

* стамина восстанавливается мгновенно (не тратится на бои);
* стартовый инвентарь увеличен до 1000 слотов;
* карточные коробки (сундуки за монеты/кристаллы) стали бесплатными;
* восстановление стамина и расширение инвентаря — бесплатные;
* ежедневный подарок: повторная попытка бесплатна, шансы наград выровнены, награды-сердечки убраны (стамина теперь бесконечная);
* выпадение лута в квестах (карты, предметы сайдквестов, монеты) стало немного чаще.

Это изменения данных одиночной игры, а не обход защиты. Они **не** предназначены для честного сравнения результатов: если когда-нибудь появятся живые PvP-серверы или лидерборды — бери обычную сборку `v_RU`.

## Как запустить

1. Распакуй `CardWars_QOL.zip` в любую папку.
2. Рядом должны лежать три объекта: `CardWars.exe`, `UnityPlayer.dll` и папка `CardWars_Data`.
3. Запусти `CardWars.exe`.

> Не перемещай `CardWars.exe` отдельно от `CardWars_Data` и `UnityPlayer.dll` — игра не найдёт ассеты и не запустится.

## Русская локализация

Русский включён по умолчанию. Переведены интерфейс и системные сообщения, имена и описания существ/заклинаний/зданий/героев, диалоги и катсцены обеих кампаний («Фионна и Кейк», «Валентинка»), обучение, квесты и описания локаций. Таблицы `RU_*.bytes` (`Menu`, `Names`, `Descriptions`, `NIS`, `Scenes`, `Tutorial`) и `LocalizationSettings.asset` (`defaultLangCode: RU`) унаследованы из ветки `main`.

Ограничения перевода: озвучка остаётся английской (аудио, не текст); одна техническая строка сетевой диагностики (`ERROR_CONNECTIVITYCONTROLLER2`) осталась английской из-за опечатки в оригинальном ключе; часть заголовков, «вшитых» в спрайты карт, не переводится таблицами.

## Сборка из исходников

Проект использует **Unity 2017.4.40f1**.

1. Открой папку проекта в Unity 2017.4.40f1 (ветка `qol-ru`).
2. `File → Build Settings` → **PC, Mac & Linux Standalone**, `Target platform: Windows`, `Architecture: x86_64`, `Development Build` — выключено.
3. Стартовая сцена добавлена в `Scenes In Build` (`Add Open Scenes`).
4. `Player Settings` → `Product Name: CardWars`.
5. **Build** → отдельная папка, например `Build\Windows-QOL`.

> **Примечание для этой версии Unity.** Иногда финальный этап сборки не дописывает `CardWars_Data\Mono` (ошибка `Failed to load mono`). Тогда скопируй содержимое `Data\MonoBleedingEdge\EmbedRuntime` из папки редактора Unity в `CardWars_Data\Mono` — там лежат нужные 64-битные `mono-2.0-sgen.dll`, `mono-2.0-bdwgc.dll`, `MonoPosixHelper.dll`. Также следи за свободным местом на диске сборки: Unity держит билд в двух копиях (`Temp\StagingArea` + цель), при нехватке места падает с `Win32 IO returned 112`.

## О форке и правах

Оригинальный порт, движок, код и все игровые ассеты (модели, текстуры, звук, персонажи «Времени Приключений») принадлежат их правообладателям. Данный репозиторий распространяет изменения локализации и офлайн-баланса; скачивая билд, ты получаешь фанатский патч поверх оригинальной игры.
